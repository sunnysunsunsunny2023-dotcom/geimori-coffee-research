## 写作质量通用要求（6 篇共同遵守）

1. 自然美式英语；先回答问题，再介绍产品；具体购买情境。
2. 允许客观讨论非 Geimori 选项（1Zpresso、Baratza、Fellow、订阅服务等），不贬低。
3. 不编造测试、测评、购买者体验、专家意见、Reddit 原话；引用社区观点须带真实 URL（子 Agent 证据回填）。
4. 不使用"最佳/最安静/零残留/一定改善"等绝对化表述。
5. 年份只用于真正需要年度更新的页面（A/B 的 2026 表述合理；C/D/E/F 为 Evergreen 不加年份）。
6. FAQ 来自真实问题（G01-G08 / 子 Agent Reddit 证据）或可验证搜索意图，不堆砌。
7. 图片：仅用核验过的真实产品图；无图时用不含磨豆机的咖啡生活场景；alt text 准确；品牌拼写 Geimori；Wirsh/Geimori 归属准确。
8. 结构化数据：不把品牌内容伪装成独立第三方测评；按页面真实内容标注。
9. 内链：遵循 content_cluster_v2 第 5 节规则（多样化锚文本、Hub 回链、不重复产品段落）。
10. 每篇发布走 Git → GitHub → PR → 人工审核 → 合并 → 发布；本批不自动发布、不合并 PR、不改 URL、不删旧文。
