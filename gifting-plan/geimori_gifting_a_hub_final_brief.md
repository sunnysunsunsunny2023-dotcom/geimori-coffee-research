## 1. 内容大纲（H2/H3，条件化）

**开篇（先答问题）**
- H2：Is a coffee grinder actually a good gift?（GEO G07 对应；SERP VERIFIED：该疑问式长尾直接成文者少）
  - 答：**有条件地是**——磨豆机适合"每天喝咖啡但用预磨粉/刀片机、愿意多花 30 秒换风味"的人；**不适合**"不爱动手、已有好磨豆机、只喝速溶/胶囊"的人。
  - 不写"所有人都需要磨豆机"。

**H2：Before you buy: 3 questions to ask（吸收 #27 的 5 步选礼，压缩为 3 问）**
1. 对方现在怎么喝咖啡？（意式/手冲/法压/冷萃/胶囊）
2. 对方已经有什么设备？（→ 见 C 场景，不重复展开）
3. 你的预算与 TA 的意愿？（送大件前是否先问过）

**H2：Gift picks by budget（预算速查，深度版在 B）**
- 按 cluster §5 半开区间展示：$25 以下 / $25–49.99 / $50–99.99 / $100–149.99 / $150–199.99 / $200–299.99 / $300–399.99 / $400+
- 每档：1 行"这个价位能买到什么" + 1 个条件化推荐（"如果 TA 主要喝手冲且预算 $150–200，GU38 的紧凑插电单剂量值得考虑"）
- 边界铁律：GU38（$179.99）不入 <$100；GU64 Gen2（$399.99）不入 <$300；T38 Gen2（$129.99）标注预售
- 价格表述：区间 + "核验于 2026-11-16，以官网实时价为准"，**不硬编码单一促销价**（第三轮修正）

**H2：Gifts by person（按收礼人速查）**
- 新手 / 老饕 / 意式玩家 / 旅行露营党 / 办公室交换 / **已经什么都有**（每类 2-4 句 + 指向对应 Spoke）
- 条件化：每类给"适合/不适合"两栏

**H2：When a grinder gift makes sense—and when it doesn't（条件化升级逻辑，不默认升级值得）**
- 值得：旧磨豆机、手摇想换电动、噪音困扰、想玩意式但没磨
- 不值得：已有好磨豆机（→ 豆/秤/课程/礼品卡），详见 C

**H2：Holiday 2026 特别提示**
- 黑五/圣诞促销期间的购物提醒：价格会变；预售商品（T38 Gen2）交付时间不保证
- 圣诞配送：以官网结算页配送估算为准，不自行推断最后下单日（BLOCKED 物流数据）

**H2：FAQ（真实意图，不堆砌）**
